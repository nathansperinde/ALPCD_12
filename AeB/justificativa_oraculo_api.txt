Alterações ao api.py

O ficheiro original continha duas implementações misturadas (copy-paste), com funções incompletas e erros de indentação, por isso não importava. A nova versão junta o melhor das duas, e a alínea top/search já funciona sobre ela.

Erros corrigidos

Funções incompletas (get_json, get_all), com try fora de indentação e dois return em get_list.
Dois pedidos HTTP seguidos (session.get e requests.get) reduzidos a um só.
Variável items usada para duas coisas, separada em results (acumulador) e items (página).

Código unificado

get_json + get_data passaram a ser get_json(endpoint, params, refresh), já com cache.
get_all + get_list passaram a ser get_list(...).
_build_url foi substituído por _url (valida domínio e caminho com urljoin e urlparse).
HEADERS ficou definido uma só vez, usado pela session.
Mensagens de erro todas em português (timeout, ligação, HTTP com código, JSON inválido, resposta que não é objeto). O dicionário HTTP_ERRORS deixou de ser usado.

Cache e paginação

A chave da cache usa a URL completa e os parâmetros.
Se não for possível gravar a cache, o programa continua (a cache é opcional).
Os params são enviados só na primeira página, porque as URLs next já os incluem.
visited passou de lista a set.

Novidade

Parâmetro transform em get_list: aplica uma função a cada item e descarta os que devolvem None, sem os contar para max_items. Assim o top N devolve sempre N exercícios válidos, mesmo que alguns não tenham nome em inglês.

Compatibilidade: get_data e get_all já não existem. Se algum colega as usar, basta acrescentar no fim do ficheiro get_data = get_json e get_all = get_list.
